# Netflix Data Analysis

## Project Overview

This project focuses on analyzing Netflix movies and TV shows using Python. The aim is to explore the dataset, identify content trends, and generate useful business insights through data analysis and visualization.

## Objectives

* Clean and prepare the Netflix dataset.
* Analyze movies and TV shows available on Netflix.
* Explore country-wise content distribution.
* Identify trends in content releases.
* Analyze content ratings and genres.
* Generate meaningful business insights.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook / VS Code
* CSV Dataset

## Tasks Performed

1. Data Cleaning and Preprocessing
2. Content Analysis
3. Country-wise Analysis
4. Release Trend Analysis
5. Rating and Genre Analysis
6. Business Insights and Visualization

## Dataset

The project uses a Netflix titles dataset containing information about movies and TV shows, including their titles, types, countries, release years, ratings, and genres.

## Key Learnings

* Data cleaning and preprocessing using Pandas.
* Exploratory Data Analysis (EDA).
* Data visualization using Matplotlib.
* Identifying patterns and trends in a dataset.
* Presenting findings in a structured format.

## Project Files

This repository contains the Python scripts, cleaned dataset, and analysis charts generated during the project.
